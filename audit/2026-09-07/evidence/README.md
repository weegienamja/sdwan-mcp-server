# Sanitized evidence index

This directory contains generated or summarized evidence only. It must not contain vManage credentials, cookies, XSRF tokens, device identifiers, alarm text, running configurations, or customer topology.

- `sbom.cdx.json`: CycloneDX runtime dependency resolution generated by pip-audit.
- `tool-inventory.json`: expected MCP tool inventory and read-only classification.
- `verification-summary.txt`: reproducible command/result summary.

Live validation printed only package version, tool names, pass/fail status, and totals. Raw tool responses were discarded.
